# Simple Calculator

A basic console calculator built with C# and .NET as part of my programming practice.

The program asks the user to enter two numbers, adds them together, and displays the result in the console.

## Features

- Accepts two numbers from the user
- Supports decimal numbers
- Calculates and displays the sum
- Simple command-line interface

## Technologies

- C#
- .NET
- Console Application

## Example

```text
=== Simpel Calculator ==
Enter a number: 10
Enter another number: 5
15
```

## Getting Started

**Requirements:** .NET SDK installed.

1. Clone the repository.
2. Open a terminal in the project directory.
3. Run the application:

```bash
dotnet run
```
